# Natural Earth 1:110m

Source: https://github.com/nvkelso/natural-earth-vector, tag `v5.1.2`, folder `geojson/`.
Natural Earth data is in the **public domain** (https://www.naturalearthdata.com/about/terms-of-use/).

- `ne_110m_land.geojson`: coastlines (printed thick)
- `ne_110m_admin_0_boundary_lines_land.geojson`: land borders between countries (printed thin)
- `ne_110m_admin_0_countries.geojson`: country shapes (app Areas, via tool/build_country_shapes.py)

Do not edit; replace the whole set when upgrading.
